# Worked practice solution

Review after your 90-minute attempt. The solution implements Command and Simple Factory without Facade. Commands hold request inputs and delegate the sample statistic to one pandas function. The factory returns an unexecuted request; the CLI is its invoker.

Run python -m pytest and python grading/grade.py. Read the six annotated branches in the teaching repository for explanations. This worked solution is for practice; the real exam changes a bounded requirement.
